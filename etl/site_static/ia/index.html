Use com IA (MCP)

Assistentes de IA compatíveis com o Model Context Protocol podem consultar estes dados diretamente. Endereço do servidor (Streamable HTTP):

https://painel-emendas.pages.dev/mcp

Ferramentas

FerramentaO que fazCusto
buscar_municipioAcha o município e o código IBGEGrátis
resumo_municipioTotal e valor por habitante; com passe, por ano, autores, favorecidos, áreas e tiposGrátis / passe
ranking_municipiosRanking por total e por habitante, no Brasil ou numa UFPasse
contratos_prefeituraFornecedores e contratos da prefeitura nos últimos 12 meses (PNCP)Passe
comprar_acessoGera a fatura Lightning do passe de 24 h—
ativar_acessoConfere o pagamento e entrega o token—

Como pagar

  1. Peça ao assistente para chamar comprar_acesso. Ele recebe uma fatura Lightning de 1.000 sats.
  2. Pague com qualquer carteira Lightning (ou deixe um agente com carteira pagar sozinho).
  3. O assistente chama ativar_acesso e recebe um token válido por 24 horas, sem cadastro e sem login.

Configuração

Em clientes que aceitam servidores remotos, adicione um servidor do tipo HTTP com o endereço acima. Exemplo de configuração JSON:

{ "mcpServers": { "emendas": { "type": "http", "url": "https://painel-emendas.pages.dev/mcp" } } }
